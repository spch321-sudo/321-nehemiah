## 並讀譯本（pr1109，2026-11-09）
「經文」分頁每一章上方有「🌐 並讀」按鈕，可選 29 種語言（和合本繁／簡、English WEB、한국어、日本語…），每一節下面附上同一節的另一種譯本（灰色小字，阿拉伯／希伯來／波斯文由右至左）；資料直接讀互動聖經的經文檔，不另存。朗讀、畫線、解經只作用在主要經文。選擇會記住，所有講義共用。

國度321空中團契《321聖經講義》尼希米記（十三章、406 節），版本 v1.0。
