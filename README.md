「🌐 中英並讀」改成逐句：每一句後面緊接著另一語言的同一句（自成一行、灰色小字）。另一語言先切句，再依長度比例對齊（1:1、1:2、2:1…），翻譯時合併或拆開的句子也能對上；已包成畫線單位的句子整句保留，朗讀、畫線不受影響。
